# Security Policy

This repository contains experimental wireless link-control reference software. It is not a security protocol and does not replace encryption, authentication, integrity protection, replay defenses, or secure key management supplied by a suitable established protocol.

The proposed packet metadata has no security properties. Do not use its node identifier, sequence, timestamp, or link scores as proof of identity or authorization. Validate any untrusted input and use established transport/link security for deployments.

No production deployment or security guarantee is implied. Please report security concerns privately to the repository maintainer before public disclosure.
